Install instructions:

Please note that this skin will only work with Winamp 3 or Winamp 5. We recommend Winamp 5 for best results.  You may download Winamp 5 at http://www.winamp.com.

1. Click the link to the file. Depending on your configuration, your computer may self-install the skin automatically and then run Winamp. If this happens, skip the next steps - you're done. If a dialogue box pops up instead, continue following these instructions.

2. Select the option to save the file, and save it to your Winamp skins directory.

3. Run Winamp from your Start menu, and open the preferences window by pressing ctrl-P.

4. Select the Skins option, then select the Max Payne 2 skin and click "switch".

Notes:

* For best visual results, we recommend enabling Alpha Blending in your Winamp skin preferences if you have not already done so.  Note that on Winamp 3 this may result in significantly reduced performance - this performance hit is greatly lessened on Winamp 5.

* If you are running Winamp 5 and you do not see song titles or other info in the track info box, ensure that the "Use FreeType Internal TTF rendering" box under Modern Skins preferences is checked.

*  You may notice that the component windows (such as Playlist Editor or Media Library) do not snap to the bottom edge of the main window.  This is normal.  There should be a gap between the main window and other windows when snapped to provide a cleaner appearance with alpha blending turned on.
