INPUT TROUBLESHOOTING

This section contains important information about possible problems that may occur with Max Payne 2 and different hardware configurations.

KEYBOARD

Task Switching:
It is recommended that you should not task switch while playing Max Payne 2.

Windows Keys
If you have the "Allow Windows Keys" option unchecked in the Max Payne 2 Options dialog, and you task switch back to Windows, these Windows keys will be disabled as long as Max Payne 2 is running.

MOUSE TROUBLESHOOTING

Generic Information:
1. Max Payne 2 supports a maximum of 5 mouse buttons.
2. The extra buttons on some mice (for example Razer Boomslang or Logitech mice) may not be configurable as game controls from in-game menus if the manufacturers' driver software (such as Logitech MouseWare) is installed. Please configure the buttons to desired keys from the mouse control panel and assign actions to those buttons in Max Payne 2.

Q: My mouse button inputs get stuck, performing the same action (shoot, dodge etc.) while playing
 Please disable ALL keyboard shortcuts from Control Panel -> Accessibility Options. Here's how:

  • Click on "Start" and select "Control Panel"
  • Click on Accessibility Options
  • On the Keyboard tab, ensure that "Use StickyKeys", "Use FilterKeys" and "Use ToggleKeys" are disabled
  • Also, you need to click on the "settings" button for all three options: StickyKeys, FilterKeys and ToggleKeys and ensure that the "Use shortcut" is unchecked on the dialog that opens.

While having this problem in-game, click on the "stuck" button to unlock it.

Another possibility when this can happen is if a program steals focus for a very short period. Please disable all background software including Messenger, ICQ and e-mail software before running the game.

Q: I am experiencing mouse lag (i.e. the screen lags behind my mouse movement).
We have noted this rare problem with for example Logitech MX700 cordless mouse and found that updating mouse drivers removes the lag. Please update your mouse drivers.

This may also happen when the graphics card renders too many frames in advance. Try upgrading your graphics card drivers or setting VSync on in your display driver control panel.

JOYSTICKS

Max Payne 2 does not directly support joysticks. However, some joystick devices such as Microsoft Sidewinder Dual Strike can be configured from the joysticks' control panel to work with Max Payne 2 by creating a custom profile.
