INSTALL & CD TROUBLESHOOTING

GENERIC INFORMATION

1. Max Payne 2 requires Administrator privileges to install or uninstall on Windows 2000 and Windows XP.

2. Max Payne 2 requires the Play CD to be in the CD Drive during the start of the game. Max Payne utilizes SecuROM technology to prevent software piracy, and copies of the game CD will not work.

COMMON PROBLEMS

Q: I get a "The InstallShield Engine (iKernel.exe) could not be installed" error message
A complete list of possible causes and ways to correct the problem exists at Installshield Knowledge Base article Q104985.

Q: I get an CRC error during installation OR
Q: The system crashes during the installation with the error "the file c:\program files\max payne2\MP2_*.ras doesn't match the file in the setup's cab file. The medium from which you are running the setup may be corrupted: contact your software vendor."
Try disabling DMA on your CD-ROM drive. Here is how:

  1. Go to Start\Settings\Control Panel
  2. Double-click the System icon in the System Properties dialog box.
  3. Select the Device Manager tab. Click the + plus sign next to the cd-rom icon.
  4. Double-click the icon for your cd-rom drive.
  5. Click the Settings tab and de-select the DMA check box in the Options panel. Click Ok twice.
  6. You probably will have to restart your computer after doing this.

Q: Max Payne never makes it beyond the splash screen
Please shut down all background applications, especially those that access the CD-ROM drive, including CD burning software and CD/DVD emulators, copy protection decryptors such as Daemon Tools. An alternate option is to try to use a different DVD-ROM, CD-ROM or CD-RW drive if available.
